# v3.17.6 → v3.17.8

- **物资箱保持横向**：参与智能排列的物资箱统一使用默认横向，不再自动旋转；其他物品的旋转规则不变。
- **新增“保留容器排列”**：让带内部储物窗口的机器、货架、笼子、背包、箱子等保持原位不转动，只整理它们周围的其他物品；不是这些类别全部固定。
- **按实际实例判断**：空容器或窗口未打开也可能固定，只检查该实例是否具有内部窗口。新模式下已固定的物资箱也保持捕获时的实际方向。
- **配置与保护**：自有 `KeepContainers` 配置默认开启，关闭后不额外固定；原“智能排列”不启用此保留规则。增加窗口资格与固定物品校验，失败时保留事务回滚；核心装箱/评分和组内排序策略不变。
