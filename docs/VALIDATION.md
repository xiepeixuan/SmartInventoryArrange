- 原始Tag所有字段仍进入严格状态指纹，同时保留不可变逐字段读数。
- 仅当精确 `CONTAINER_TEMP_TAG.valueDouble` 的有限值变化，且身份/成员/父容器、数量、位置方向与占格、可移动性、分类、原生方向、名称与排序特征、其他全部Tag状态均不变时，才进行最新原生槽位检查和第二次严格读取。
- 全部复核成功后，统一更新观察快照、逐字段基准与movable指纹；不向游戏写入旧温度或液体状态。
- 化学反应、液体成分/含量/水质、鉴定/其他物品状态、缺失/新增Tag、温度NaN/Infinity或同Tag其他字段变化仍取消。重新点击会捕获最新输入。
- 仅会话标识规范化该精确温度字段，避免自然温度变化重置搜索前沿；严格指纹仍包含实际温度。
- 目标检查以后保持严格提交检查；提交期变化仍触发取消/原布局回滚。固定物品状态和位置在两种模式都检查。
- 求解器、视觉评分、偏好模型、实例组内排序规则、物资箱方向与原回滚函数保持不变。没有放宽完整性约束，也没有把温度例外应用到所有状态。
